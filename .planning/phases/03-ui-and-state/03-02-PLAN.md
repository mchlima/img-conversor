**1. `components/DropZone.vue`** (per D-01, D-02, D-03, D-11, INPT-01, INPT-02):

Structure:
- `<div>` with drag event handlers (`@dragover.prevent`, `@dragleave`, `@drop.prevent`) + `@click` to open file picker
- Hidden `<input ref="fileInput" type="file" multiple accept="image/jpeg,image/png,image/webp">` with `@change`
- Two visual modes controlled by `images.value.length > 0`:
  - **Expanded** (no images): Large dashed border area (~200px height), upload icon (UIcon name="i-heroicons-arrow-up-tray"), `$t('dropzone.title')`, `$t('dropzone.subtitle')`, `$t('dropzone.privacy')` trust signal (D-11)
  - **Compact** (has images): Smaller strip (~60px), shows `$t('dropzone.replace')` text
- Visual feedback: `isDragOver` ref toggles border/bg classes (e.g., `border-primary bg-primary/5` when dragging over, `border-neutral-300` otherwise)

Script:
```typescript
const { images, addImages } = useImageStore()
const isDragOver = ref(false)
const fileInput = useTemplateRef<HTMLInputElement>('fileInput')
const hasImages = computed(() => images.value.length > 0)

function onDrop(e: DragEvent) {
  isDragOver.value = false
  const files = Array.from(e.dataTransfer?.files ?? []).filter(f => f.type.startsWith('image/'))
  if (files.length) addImages(files)
}
function onFileChange(e: Event) {
  const input = e.target as HTMLInputElement
  const files = Array.from(input.files ?? [])
  if (files.length) addImages(files)
  input.value = ''  // reset so same file can be re-selected
}
function openPicker() {
  fileInput.value?.click()
}
```

CRITICAL: `e.preventDefault()` on BOTH dragover and drop (use `.prevent` modifier). Without it, the browser navigates to the dropped file URL. Also reset `input.value = ''` after reading files so re-selecting the same file triggers change.

**2. `components/ImageCard.vue`** (per D-04, D-05, D-06, INPT-03, INPT-04, OUTP-01, OUTP-02, OUTP-03, OUTP-05):

Props: `defineProps<{ item: ImageItem }>()`

Layout: Horizontal row (D-05, one per line) using flexbox. Contains:
- **Thumbnail**: `<img :src="item.previewUrl" :alt="item.name">` — max-height ~48px, aspect-ratio auto, rounded
- **Filename**: `item.name` truncated with `truncate` class
- **Original size** (INPT-04): `formatBytes(item.originalSize)`
- **Status badge** (OUTP-05): `<UBadge :color="statusColor" :label="$t('status.' + item.status)" />` where `statusColor` is a computed: `{ idle: 'neutral', processing: 'warning', done: 'success', error: 'error' }[item.status]`
- **Converted size** (OUTP-01): Show only when `item.status === 'done'`: `formatBytes(item.convertedSize!)`
- **Savings** (OUTP-02): Show only when `item.status === 'done'`: compute `((originalSize - convertedSize) / originalSize * 100).toFixed(1)`. If positive (file shrunk), show in green text like `-67.3%` with `$t('card.savings')`. If negative (file grew), show in red text like `+12.5%` with `$t('card.increase')`.
- **Download button** (OUTP-03): `<UButton>` with download icon, disabled unless `item.status === 'done'`, calls `downloadImage()`
- **Remove button** (D-06): `<UButton>` with X icon (`i-heroicons-x-mark`), calls `removeImage(item.id)`, variant `ghost`, disabled when `item.status === 'processing'`
- **Error message**: Show `item.error` in red text when `item.status === 'error'`

Download function (OUTP-03):
```typescript
function downloadImage() {
  if (!props.item.convertedBlob) return
  const { options } = useConvertOptions()
  const extMap: Record<string, string> = { 'image/jpeg': 'jpg', 'image/png': 'png', 'image/webp': 'webp' }
  const ext = extMap[options.value.format] || 'webp'
  const baseName = props.item.name.replace(/\.[^.]+$/, '')
  const url = URL.createObjectURL(props.item.convertedBlob)
  const a = document.createElement('a')
  a.href = url
  a.download = `${baseName}.${ext}`
  document.body.appendChild(a)
  a.click()
  document.body.removeChild(a)
  setTimeout(() => URL.revokeObjectURL(url), 100)
}
```
CRITICAL: `document.body.appendChild(a)` before `click()` is required for Firefox. Revoke URL after 100ms delay. Use output format extension (not original).
