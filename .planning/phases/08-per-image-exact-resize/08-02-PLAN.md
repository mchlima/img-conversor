3. In components/ImageCard.vue `<script setup>`:
   a. Destructure `updateImageResize` from `useImageStore()` (already has `removeImage`)
   b. Compute aspect ratio for THIS image: `const aspectRatio = computed(() => props.item.originalWidth && props.item.originalHeight ? props.item.originalWidth / props.item.originalHeight : 1)`
   c. Create local refs synced from the item's reactive state:
      ```
      const localW = ref(props.item.resizeWidth)
      const localH = ref(props.item.resizeHeight)
      watch(() => props.item.resizeWidth, v => { localW.value = v })
      watch(() => props.item.resizeHeight, v => { localH.value = v })
      ```
   d. Create `onCardWidthChange(val: number | null)`:
      - If val is null, return
      - Clamp: `const clamped = Math.min(val, props.item.originalWidth || Infinity)` (RSZN-15)
      - Compute height maintaining aspect ratio: `const newH = Math.max(1, Math.round(clamped / aspectRatio.value))`
      - Clamp height: `const clampedH = Math.min(newH, props.item.originalHeight || Infinity)` (RSZN-15)
      - Update local refs: `localW.value = clamped; localH.value = clampedH`
      - Call `updateImageResize(props.item.id, clamped, clampedH)` (RSZN-12 — marks override)
   e. Create `onCardHeightChange(val: number | null)` — mirror logic (compute width from height * aspectRatio)

4. In components/ImageCard.vue `<template>`:
   Add a conditional row that appears ONLY when `options.resizeMode === 'exact'`. Place it AFTER the status badge area, as a new row below the main card content. Use a compact inline layout:
   ```html
   <div v-if="options.resizeMode === 'exact'" class="flex items-center gap-2 mt-1 pt-1 border-t border-neutral-100">
     <span class="text-xs text-neutral-500">{{ $t('card.card_width') }}</span>
     <UInput
       type="number"
       :model-value="localW"
       size="xs"
       class="w-20"
       @update:model-value="v => onCardWidthChange(Number(v))"
     />
     <span class="text-xs text-neutral-500">{{ $t('card.card_height') }}</span>
     <UInput
       type="number"
       :model-value="localH"
       size="xs"
       class="w-20"
       @update:model-value="v => onCardHeightChange(Number(v))"
     />
     <UBadge v-if="item.resizeOverride" color="info" :label="$t('card.card_override')" size="xs" />
   </div>
   ```

   IMPORTANT: The card layout currently uses `flex items-center` in a single row. Change the outer div to a flex-col wrapper so the resize row appears below:
   - Wrap existing content in a `<div class="flex items-center gap-3 ...">` (inner row)
   - The resize fields row goes below it
   - The outer card div becomes the flex-col container with padding

5. Keep the card visually clean — the resize row is compact (xs size inputs, short labels).
