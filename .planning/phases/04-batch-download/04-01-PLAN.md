3. **Create `utils/downloadAll.ts`** — new file containing the ZIP generation logic:
   - Import `{ zip }` from `'fflate'` and `ImageItem`, `OutputFormat` from `'~/types'`
   - Export an async function `downloadAll(images: ImageItem[], format: OutputFormat): Promise<void>`
   - Build extension map: `{ 'image/jpeg': 'jpg', 'image/png': 'png', 'image/webp': 'webp' }`
   - Iterate images, skip items where `convertedBlob` is null
   - **Deduplicate filenames** to prevent silent overwrites: use a `Map<string, number>` to track seen keys; append `-2`, `-3` etc. for duplicates (per Pitfall 3 in RESEARCH.md)
   - For each image: strip original extension from `item.name`, append new extension, convert `item.convertedBlob` to `Uint8Array` via `new Uint8Array(await item.convertedBlob.arrayBuffer())`
   - Build `zippable: Record<string, Uint8Array>` object
   - Wrap fflate's callback `zip()` in a Promise (NOT `zipSync` — async avoids blocking UI):
     ```typescript
     const zipData = await new Promise<Uint8Array>((resolve, reject) => {
       zip(zippable, (err, data) => {
         if (err) reject(err)
         else resolve(data)
       })
     })
     ```
   - Generate timestamp filename per D-01: `img-conversor-YYYY-MM-DD-HHmmss.zip` using local time:
     ```typescript
     const now = new Date()
     const pad = (n: number) => String(n).padStart(2, '0')
     const ts = `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}-${pad(now.getHours())}${pad(now.getMinutes())}${pad(now.getSeconds())}`
     ```
   - Trigger download using the Firefox-safe anchor pattern from ImageCard.vue:
     ```typescript
     const blob = new Blob([zipData], { type: 'application/zip' })
     const url = URL.createObjectURL(blob)
     const a = document.createElement('a')
     a.href = url
     a.download = `img-conversor-${ts}.zip`
     document.body.appendChild(a)
     a.click()
     document.body.removeChild(a)
     setTimeout(() => URL.revokeObjectURL(url), 100)
     ```
