2. **utils/hasAlpha.ts** — Create transparency detection utility. Exports a single async function `hasAlpha(file: File): Promise<boolean>`. Implementation:
   - Decode file via `createImageBitmap(file)`
   - Downsample to max 200px on longest side for performance
   - Draw to OffscreenCanvas at downsampled size
   - Scan alpha channel (every 4th byte starting at index 3) via getImageData
   - Return `true` if ANY pixel has alpha < 255
   - Clean up: `bitmap.close()`, set canvas width/height to 0
   - This function should ONLY be called on PNG files (`file.type === 'image/png'`). Add a JSDoc comment stating this.

3. **utils/guardCanvas.ts** — Create iOS Safari pixel limit guard. Exports:
   - `const IOS_CANVAS_PIXEL_LIMIT = 16_777_216` (named export)
   - `function guardCanvasDimensions(width: number, height: number): { width: number; height: number; scaled: boolean }` — If width*height <= limit, return original dims with `scaled: false`. If over limit, scale both dimensions down proportionally using `Math.sqrt(limit / (width * height))` as the scale factor, floor both results, return with `scaled: true`. Per D-01 discretion: auto-scale rather than reject (less friction for users).
