  <action>
Create `composables/useProcessor.ts` — a stateless composable that exports a single `convert` function. This is the core of the entire application.

**Signature:**
```typescript
export function useProcessor() {
  const convert = async (file: File, opts: ConvertOptions): Promise<Blob> => { ... }
  return { convert }
}
```

**Implementation flow — the convert function must follow this exact order:**

1. **Decode:** `const bitmap = await createImageBitmap(file, { imageOrientation: 'from-image' })` — auto-correct EXIF rotation. If the options dict form is not supported (throws), fall back to `createImageBitmap(file)`.

2. **Compute target dimensions:**
   - If `opts.resizeMode === 'none'`: targetW = bitmap.width, targetH = bitmap.height
   - If `opts.resizeMode === 'proportional'`: targetW = Math.round(bitmap.width * opts.resizePercent / 100), targetH = Math.round(bitmap.height * opts.resizePercent / 100). This satisfies RSZN-04 (aspect ratio preserved).
   - If `opts.resizeMode === 'exact'`: targetW = opts.resizeWidth ?? bitmap.width, targetH = opts.resizeHeight ?? bitmap.height
   - Ensure targetW >= 1 and targetH >= 1 (floor to 1)

3. **iOS Safari guard:** Call `guardCanvasDimensions(targetW, targetH)` from utils/guardCanvas.ts. Use the returned dimensions. If `scaled` is true, log a console.warn: `[useProcessor] Image auto-scaled from ${targetW}x${targetH} to fit iOS Safari canvas limit`.

4. **Resize via @jsquash/resize** (if dimensions differ from original):
   - Draw bitmap to a temporary OffscreenCanvas at bitmap's original size
   - Extract ImageData via getImageData
   - Close bitmap immediately: `bitmap.close()`
   - Dynamically import @jsquash/resize: `const { default: resize } = await import('@jsquash/resize')`
   - Resize: `const resizedData = await resize(imageData, { width: guardedW, height: guardedH })`
   - Clean up temp canvas: `tempCanvas.width = 0; tempCanvas.height = 0`
   - If NO resize needed (same dims), still extract ImageData from canvas and close bitmap.

5. **Encode — branch by format:**

   **WebP path (CONV-04 — Safari safe):**
   - Dynamically import: `const { encode: encodeWebP } = await import('@jsquash/webp')`
   - Encode: `const arrayBuffer = await encodeWebP(imageData, { quality: opts.quality })` — quality is 0-100 integer, maps directly from UI slider. Do NOT divide by 100.
   - Create blob: `new Blob([arrayBuffer], { type: 'image/webp' })`
   - NEVER use canvas.convertToBlob for WebP — Safari silently outputs PNG.

   **JPEG path (INFR-04 — white background for transparency):**
   - Create final OffscreenCanvas at target dimensions
   - Fill with backgroundColor FIRST: `ctx.fillStyle = opts.backgroundColor; ctx.fillRect(0, 0, w, h)`
   - CRITICAL (Open Question 1 from RESEARCH.md): Do NOT use `ctx.putImageData()` after fillRect — putImageData overwrites all pixels including fill. Instead, create a temporary OffscreenCanvas from the ImageData, then use `ctx.drawImage(tempCanvas, 0, 0)` on the final canvas. This preserves the fill because drawImage composites (respects alpha), while putImageData does raw pixel copy.
   - Encode: `await finalCanvas.convertToBlob({ type: 'image/jpeg', quality: opts.quality / 100 })` — quality is 0.0-1.0 for Canvas API. DIVIDE by 100.
   - Clean up final canvas.

   **PNG path:**
   - Create final OffscreenCanvas at target dimensions
   - Use `ctx.putImageData(imageData, 0, 0)` — no fill needed for PNG (supports transparency)
   - Encode: `await finalCanvas.convertToBlob({ type: 'image/png' })` — quality parameter is ignored for PNG
   - Clean up final canvas.

6. **Memory cleanup after EVERY path:**
   - `bitmap.close()` (if not already closed)
   - All OffscreenCanvas instances: set `.width = 0; .height = 0`
   - Do NOT store ImageData or OffscreenCanvas in any state/ref

**Anti-patterns to avoid (from RESEARCH.md):**
- NEVER use `toDataURL` — always `convertToBlob`
- NEVER use `canvas.convertToBlob('image/webp')` — Safari silently falls back to PNG
- NEVER store ImageData in reactive state
- NEVER use `putImageData` when a background fill is needed (JPEG path) — it overwrites

**Error handling:**
- Wrap the entire convert function body in try/catch
- On error, ensure all cleanup still happens (use try/finally for bitmap.close and canvas cleanup)
- Re-throw with a descriptive message: `throw new Error(\`Conversion failed for \${file.name}: \${originalError.message}\`)`
