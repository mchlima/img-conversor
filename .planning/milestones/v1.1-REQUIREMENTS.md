# Requirements: Img Conversor v1.1

**Defined:** 2026-03-24
**Core Value:** Conversão de formato + redimensionamento + controle de qualidade em uma única operação — sem fricção.

## v1.1 Requirements

### Layout

- [x] **LAYT-01**: ControlPanel exibido como barra horizontal acima da lista de imagens (não mais como sidebar lateral)
- [x] **LAYT-02**: ControlPanel visível apenas quando há imagens selecionadas na lista
- [x] **LAYT-03**: Botão "Baixar Todas" posicionado dentro do ControlPanel (não como componente separado)
- [x] **LAYT-04**: Botão "Baixar Todas" visível apenas quando há pelo menos uma imagem com status "done" na lista
